A single-line excuse from a GPS that routed its driver through a swamp to avoid a toll—and remains completely unrepentant: "Recalculating... no, I meant the swamp. It saved you eleven minutes and a four-dollar toll. The car was a small price to pay. You have arrived." Written for the make.fun bounty "The GPS Swears It Was a Shortcut."

## Run it

```sh
node main.ts
```
